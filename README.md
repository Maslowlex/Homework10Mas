# 1. Алгоритм и блок-схема

## Алгоритм решения
1. **НАЧАЛО**
2. Объявление переменных: массив `products` из 3 элементов типа `Product`, текущая дата `today`, счетчик `i`.
3. Получение текущей системной даты (вызов `getCurrentDate()`).
4. Вывод текущей даты на экран.
5. **Цикл ввода (для i от 0 до 2):**
   * Вывод заголовка "Ввод товара №...".
   * Запрос и ввод наименования товара.
   * Запрос и ввод даты производства (ДД.ММ.ГГГГ).
   * Запрос и ввод срока годности (ДД.ММ.ГГГГ).
   * Запрос и ввод цены.
   * Запрос и ввод номера серии.
6. Вывод шапки таблицы.
7. **Цикл вывода (для i от 0 до 2):**
   * Вывод данных текущего товара (`printProduct`).
8. Вывод подвала таблицы.
9. Вывод заголовка "Результат обработки (Товары, годные на текущую дату)".
10. Установка флага `found = 0`.
11. **Цикл проверки (для i от 0 до 2):**
    * **Условие:** Если срок годности товара больше или равен текущей дате (вызов `isValid`):
      * Вывод наименования товара и его срока годности.
      * Установка флага `found = 1`.
12. **Условие:** Если `found == 0`:
    * Вывод сообщения "Нет товаров с действительным сроком годности".
13. **КОНЕЦ**
